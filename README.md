# SG Quotation & Proposal Management Kanban – Steps 1–6
This build adds:
- **Step 5**: Dashboards (Offers over time, Order Intake over time, Workload by team, Outcome snapshot, Won breakdown by dimension). Granularity: Weekly/Monthly/Yearly. Customizable visibility.
